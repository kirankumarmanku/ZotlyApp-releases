# Zotly for macOS

Downloads and the update feed for [Zotly](https://github.com/kirankumarmanku/ZotlyApp).

- **Latest version:** see [Releases](https://github.com/kirankumarmanku/ZotlyApp-releases/releases).
- `appcast.xml` is the Sparkle feed an installed copy checks. It is generated by
  `scripts/publish-macos-update.sh` in the main repository; editing it by hand will
  break update signatures.

This repository is public because an installed app has to fetch updates without
credentials. The source lives in a private repository.
